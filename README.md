# TP3 Mini Scanner

## Description
Script Python qui utilise nmap pour scanner localhost.

## Fonctionnalités
- Scan rapide
- Détection de services
- Scan personnalisé

## Utilisation
python3 tp3_kali_scanner.py

## Résultats
Les scans sont enregistrés dans le dossier reports/

## Éthique
Scan uniquement sur 127.0.0.1
