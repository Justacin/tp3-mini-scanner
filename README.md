# TP3 Mini Scanner

## Description
Script Python utilisant nmap pour scanner localhost (127.0.0.1).

## Fonctionnalités
- Scan rapide (top 100 ports)
- Détection de services (-sV)
- Scan personnalisé

## Utilisation
python3 tp3_kali_scanner.py

## Résultats
Les résultats sont enregistrés dans le dossier reports/

## Éthique
- Scan uniquement localhost
- Aucun scan externe autorisé
